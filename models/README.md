# Required MediaPipe Models

This project uses the following model files:

| File | Purpose |
|---|---|
| `face_landmarker.task` | Detects facial landmarks |
| `hand_landmarker.task` | Detects hand landmarks |
| `selfie_segmenter.tflite` | Separates the person from the background |

## Setup

Place all three model files in this `models/` directory before running the application.

The model files are not included in this repository yet. Download them from their original sources and check their licence terms before redistributing them.
